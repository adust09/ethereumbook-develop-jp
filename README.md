## ローカルビルド

[mdBook](https://rust-lang.github.io/mdBook/) v0.4.36 が必要です。

```bash
# mdBook のインストール
cargo install --version 0.4.36 mdbook

# ローカルサーバー起動（ホットリロードあり）
mdbook serve

# 静的ファイルとしてビルド
mdbook build
```
